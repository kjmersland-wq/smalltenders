# Small Tenders

Public contracts small firms can actually win.

Edited list. Open official sources only (TED and national notice portals). No AI. No portal.

Site: [smalltenders.com](https://smalltenders.com)

## GitHub Pages

1. Create a public repo named `smalltenders`.
2. Upload these files to the default branch (`main`).
3. Settings → Pages → Deploy from branch → `main` / root.
4. At your registrar, set:
   - `A` `@` → `185.199.108.153` (and the other three GitHub Pages IPs), or
   - `CNAME` `www` → `YOURUSER.github.io`
5. Keep the `CNAME` file in this repo (`smalltenders.com`).

## Email

Point `hello@smalltenders.com` at the mailbox you actually read.
The form on the page is a simple `mailto:` until you add a free form endpoint.
